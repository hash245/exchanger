# Обменник — Telegram-бот + Mini App

- `index.html` — Mini App (GitHub Pages): выбор пары, сумма, живой курс, адрес получения.
- Поддерживается крипто ↔ крипто и покупка крипты за рубли по СБП (RUB → BTC/ETH/USDT/TON/LTC/TRX).
- `bot/` — бот на Python (aiogram 3): принимает заявку из приложения, заново считает курс,
  выдаёт адрес для оплаты и отправляет заявку админам на подтверждение.

## Как это связано

1. В боте кнопка «💱 Обменять» открывает Mini App.
2. Клиент заполняет форму и нажимает «Создать заявку». Приложение передаёт данные боту
   через `Telegram.WebApp.sendData` и закрывается. Отдельный сервер для этого не нужен.
3. Бот проверяет пару, сумму и адрес, считает курс сам (цифрам из приложения не доверяет)
   и просит подтвердить. Дальше работает тот же сценарий, что и в чате: оплата,
   кнопка «Я оплатил», подтверждение админом.

## Запуск

**Mini App:** Settings → Pages → Deploy from branch → `main` / `(root)`.
Приложение будет доступно по адресу `https://hash245.github.io/exchanger/`.

**Бот:**
```bash
cd bot
pip install -r requirements.txt
cp .env.example .env   # токен, ID админов, адреса кошельков, WEBAPP_URL
python bot.py
```

## Рубли по СБП

- Реквизиты задаются в `.env`: `SBP_PHONE`, `SBP_BANK`, `SBP_NAME`, а лимиты — `RUB_MIN` и `RUB_MAX`.
  Комиссия для рублей отдельная: `FEE_RUB_PERCENT` (по умолчанию 3%).
- Курс рубля берётся через USDT/RUB на CoinGecko.
- К сумме добавляются случайные копейки (например, 10 000,47 ₽): по ним оператор
  находит конкретный перевод в банковской выписке.
- После «Я оплатил» бот просит скриншот или PDF чека и пересылает его админам вместе с заявкой.
- Если `SBP_PHONE` не задан, приём рублей отключён.

Если `WEBAPP_URL` не указан, обмен проходит обычными кнопками в чате.

Монеты заданы в двух местах: `COINS` в `index.html` и `CURRENCIES` в `bot/config.py`.
При добавлении новой монеты нужно обновить оба списка.

## Перед запуском на реальных деньгах

- Автопроверка входящих транзакций (TronGrid, TonAPI, Blockchair) вместо ручной.
- Уникальный депозитный адрес или memo на каждую заявку.
- `RedisStorage` для FSM вместо памяти.
- Приём рублей на личную карту по СБП: банки по 115-ФЗ блокируют карты за частые переводы
  от разных людей. Платежи от третьих лиц (так называемые «дропы») — отдельный риск:
  деньги могут оказаться похищенными, и тогда претензии предъявят получателю.
- Лицензия и KYC/AML: в Казахстане обмен криптовалют для третьих лиц требует лицензии (например, через МФЦА).
